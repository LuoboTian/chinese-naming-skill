# 中文取名 Skill

一个面向 Agent 的中文取名 Skill。它会收集姓氏、性别和出生时间，按明确的历法与时区口径分析传统八字五行，并从《三字经》《道德经》《诗经》《楚辞》、唐诗、宋词等典籍中提取意象，推荐名字并提供结构化解析。

## 功能

- 询问姓氏、性别、出生时间、出生地/时区和命名偏好；
- 按用户确认的公历/农历和时间口径分析四柱与五行；
- 推荐单名或双名，并检查音韵、谐音、字形和书写难度；
- 解释典籍出处、逐字寓意、传统五行、拼音声调和笔画；
- 支持换一批、指定典籍、指定风格和候选名对比；
- 对无法核实的八字、出处和笔画数据保持透明，不编造精确结果。
- 提供零第三方依赖的本地命名脚本，并附带声调、笔画、五行、汉字和诗词参考数据。
- 支持对用户本地提供的《诗经》《楚辞》等经典原文目录进行出处检索。

## 使用说明

把本仓库作为一个 Skill 安装到 Agent 的 skills 目录，然后直接提出类似请求：

```text
帮我给宝宝取几个名字
```

Skill 会继续询问：

1. 姓氏及是否复姓；
2. 性别或偏好的中性程度；
3. 公历/农历出生年月日时分；
4. 出生地或时区；
5. 单名/双名、风格、典籍偏好、避讳字和辈分字。

如果不希望提供出生时间，也可以说“只按诗经和音韵取名”，此时结果会明确标注未进行八字分析。

## 本地计算

出生时间完整时，可以运行本地脚本获取 JSON 结果：

```bash
python3 scripts/naming.py \
  --birth "2024-05-20 14:30" \
  --calendar gregorian \
  --gender neutral \
  --surname "王" \
  --style classical \
  --name-length 2 \
  --count 10 \
  --json
```

参数说明：

- `--name-length 1`：单名；`--name-length 2`：双名；
- `--gender male/female/neutral`：性别倾向；
- `--calendar gregorian/lunar`：公历或农历；
- `--taboo`：逗号分隔的避讳字；
- `--generation`：字辈字；
- `--json`：输出机器可读结果。
- `--classics-root`：可选，本地经典原文目录；候选生成时会自动检索出处。

如果需要核对完整原文，可准备一个本地经典文本目录，再运行：

```bash
python3 scripts/search_classics.py \
  --root /path/to/classics \
  --book 诗经 \
  --query 清扬
```

本项目只提供检索适配器，不复制整套经典原文；原文目录的使用许可由提供者自行负责。

脚本只使用 Python 标准库，不需要安装第三方依赖。出生时分未知时，脚本会用子时作为占位计算并明确警告；正式解读不得把该结果当作精确时柱。

### 计算边界

- 月柱节气目前使用参考表的近似日期；出生日期接近节气交界时，应进一步使用专业历法核对。
- 出生地目前用于对话说明，脚本尚未进行真太阳时或经纬度修正。
- 农历转换支持常规日期，但闰月等边界输入仍应人工复核。
- 单字五行、康熙笔画、五格和字义吉凶属于传统姓名学参考，不是科学测量，也不构成命运预测。

## 姓名语料统计

本项目不提交原始百万级姓名语料，只保留精简的给定名统计。
它只用于提示常见度、样本数和性别倾向，不用于八字、五行或典籍出处判断。

重新构建统计数据：

```bash
python3 scripts/build_name_stats.py \
  /path/to/local-name-corpus.txt \
  data/name_stats.json \
  --limit 100000
```

原始语料包含少量未知性别和 badcase，因此报告中的语料数字只能作为辅助参考，不能等同于官方人口统计或真实重名率。

## 输出内容

每个候选名字包含：

- 典籍出处与上下文/意象说明；
- 逐字寓意和合名含义；
- 传统五行归类及采用的口径；
- 普通话拼音、声调和与姓氏的连读分析；
- 笔画、所采用的笔画体系及不确定性说明；
- 适用优点、潜在谐音和登记/书写注意事项。

## 安装

不同 Agent 的 Skill 目录可能不同。以 Codex/兼容 Agent 为例，可将仓库目录复制到项目级 Skill 目录：

```bash
mkdir -p .cursor/skills
cp -R /path/to/name-skill .cursor/skills/chinese-naming
```

也可以直接把本仓库目录作为项目 Skill 使用。核心文件是根目录的 [`SKILL.md`](SKILL.md)。

## 设计原则

八字五行、单字五行、康熙笔画和五格剖象存在不同算法与流派。本项目把它们作为传统文化参考和候选筛选维度，不将名字与命运、健康或财富建立确定因果关系。典籍出处无法核实时，会标注为意象化借鉴，不伪造原文。

## 项目特色

本项目自主设计了从信息收集、历法口径确认、候选生成、语料筛选到出处核验的完整流程，重点支持单名、中性取向、传统典籍意象和不确定性说明。
