# 经典原文参考源

## 作用

本目录约定了经典原文的检索方式。用户可以自行准备包含《诗经》《楚辞》《道德经》《三字经》、唐诗、宋词等文本的本地目录，作为出处核对和意象检索来源。

## 使用规则

本项目不直接复制整套经典原文。使用者准备好本地原文目录后，可以通过：

```bash
python3 scripts/search_classics.py \
  --root /path/to/classics \
  --book 诗经 \
  --query 清扬
```

检索结果只用于核对篇名、原文和上下文。找不到原文时，必须标记为“意象化借鉴”，不能伪造出处。

## 使用边界

检索结果只用于核对篇名、原文和上下文。原文目录的版权和使用许可由提供者自行负责；找不到原文时，必须标记为“意象化借鉴”，不能伪造出处。
